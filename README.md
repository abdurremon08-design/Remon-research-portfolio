## 3. Run the Website Locally

To run the project on your computer:

### Requirements

Install [Node.js LTS](https://nodejs.org/) if it is not already installed.

### Installation

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local address displayed in your terminal, usually:

```text
http://localhost:5173
```

### Production Build

To create an optimized production build, run:

```bash
npm run build
```

The generated website files will be available in the `dist` folder.

To preview the production build locally:

```bash
npm run preview
```

## 4. Website Deployment

This portfolio is deployed through **Cloudflare Workers** and connected to its GitHub repository.

Whenever changes are committed and pushed to the connected GitHub branch, Cloudflare can automatically build and deploy the updated website.

### Deployment Information

* Hosting platform: Cloudflare Workers
* Source code: GitHub
* Build tool: Vite
* Build command: `npm run build`
* Build output directory: `dist`

## 6. Images and Research Photographs

Research photographs and fieldwork images are stored in:

```text
public/images/
```

When adding new photographs:

* Use optimized JPG, JPEG, or WebP images.
* Keep filenames descriptive and organized.
* Reference images using paths such as `/images/example-photo.jpg`.
* Avoid unnecessarily large image files.
* Ensure that photographs are appropriate for public academic presentation.

## 9. Research and Academic Accuracy

The portfolio is intended for academic applications, research opportunities, and professional networking.

All information should accurately represent:

* Research activities and project involvement
* Individual responsibilities and contributions
* Laboratory techniques actually performed
* Supervisors and institutional affiliations
* Research findings and manuscript status
* Academic qualifications and language proficiency

Manuscripts should not be described as published unless publication has been confirmed. Contributions to collaborative research should be distinguished from independent research leadership.

Photographs, documents, and personal information should only be published when appropriate permission has been obtained.
